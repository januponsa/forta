## PROTOKOL EKSEKUSI ANTIGRAVITY (ZERO-SKIP & ZERO-ERROR)

Dokumen ini dirancang khusus agar mudah dipahami, diproses, dan dieksekusi oleh Antigravity tanpa ada satu pun skenario atau *cell* yang terlewat. Ikuti instruksi kerja berikut secara ketat:

1. **Prinsip Zero-Skip (Anti-Terlewat):**
   - Terdapat tepat **203 Kasus Uji** (`No. 1` s.d. `No. 203`) yang terbagi ke dalam **11 Modul**.
   - Eksekusi wajib dilakukan **per Modul secara berurutan** (Batch 1: `AUTH` $\rightarrow$ Batch 2: `PUB` $\rightarrow$ ... $\rightarrow$ Batch 11: `NFR`). Jangan melompati nomor urut atau menggabungkan beberapa ID Kasus Uji menjadi satu.
2. **Aturan Pengisian Nilai Status (Wajib Presisi):**
   - Agar rumus `=COUNTIF` dan `=COUNTIFS` pada Sheet `Ringkasan` di file `Skenario_Black_Box_Testing_FORTA.xlsx` tidak rusak atau gagal menghitung, nilai yang dimasukkan ke **Kolom N (`Status`)** pada Sheet `Skenario Uji` **HANYA BOLEH** salah satu dari 5 teks eksak berikut (peka huruf besar/kecil):
     - `Lulus`
     - `Gagal`
     - `Terblokir`
     - `Belum Diuji`
     - `Tidak Berlaku`
3. **Skrip Sinkronisasi Hasil ke File Excel Asli (`update_forta_excel.py`):**
   - **DILARANG** menyimpan ulang file Excel menggunakan `pandas.to_excel()` karena akan menghapus seluruh rumus di Sheet `Ringkasan`, `Kalkulator Nilai`, dan `Matriks Keterlacakan`.
   - Gunakan skrip `openpyxl` berikut untuk mencatat hasil setiap selesai menguji satu modul:

```python
import openpyxl
from datetime import datetime

def catat_hasil_uji(excel_path, hasil_modul):
    """
    hasil_modul: dict dengan key = ID Kasus Uji (misal 'TC-AUTH-01')
    value = dict {'aktual': '...', 'status': 'Lulus'|'Gagal'|'Terblokir'|'Tidak Berlaku', 'catatan': '...'}
    """
    VALID_STATUS = {"Lulus", "Gagal", "Terblokir", "Belum Diuji", "Tidak Berlaku"}
    wb = openpyxl.load_workbook(excel_path)
    ws = wb["Skenario Uji"]

    # Baris data Skenario Uji berada di baris 5 s.d. 207 (203 skenario)
    updated_count = 0
    for row in range(5, 208):
        tc_id = ws.cell(row=row, column=2).value  # Kolom B: ID Kasus Uji
        if tc_id in hasil_modul:
            data = hasil_modul[tc_id]
            assert data["status"] in VALID_STATUS, f"Status tidak valid untuk {tc_id}: {data['status']}"
            
            ws.cell(row=row, column=13).value = data["aktual"]  # Kolom M: Hasil Aktual
            ws.cell(row=row, column=14).value = data["status"]  # Kolom N: Status
            ws.cell(row=row, column=16).value = "Antigravity AI" # Kolom P: Penguji
            ws.cell(row=row, column=17).value = datetime.now().strftime("%Y-%m-%d") # Kolom Q: Tanggal Uji
            
            if data.get("catatan"):
                catatan_lama = ws.cell(row=row, column=18).value or ""
                ws.cell(row=row, column=18).value = f"{catatan_lama} | [Hasil]: {data['catatan']}".strip(" |")
            updated_count += 1

    wb.save(excel_path)
    print(f"Berhasil memperbarui {updated_count} skenario pada {excel_path}.")
```

## SHEET 4: MATRIKS KETERLACAKAN (`Matriks Keterlacakan`)

- **Judul Sheet (Cell A1):** `MATRIKS KETERLACAKAN KEBUTUHAN (REQUIREMENTS TRACEABILITY MATRIX / RTM)`
- *Catatan Rumus Excel:*
  - Kolom D (`Jumlah Kasus Uji`): `=SUMPRODUCT(--ISNUMBER(SEARCH(A{row},'Skenario Uji'!$D$5:$D$207)))`
  - Kolom E (`Jumlah Lulus`): `=SUMPRODUCT(--ISNUMBER(SEARCH(A{row},'Skenario Uji'!$D$5:$D$207)),--('Skenario Uji'!$N$5:$N$207="Lulus"))`
